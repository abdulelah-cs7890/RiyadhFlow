## Capture tools

- **Windows** — Snipping Tool or `Win+Shift+S`. For mobile sizing, open Chrome DevTools (F12), toggle device toolbar (`Ctrl+Shift+M`), set to 390×844, then use the DevTools 3-dot menu → "Capture screenshot".
- **macOS** — `Cmd+Shift+5` for screen capture. Same DevTools mobile approach.

Keep PNGs under ~500 KB so the README loads fast.
